A **premium multilingual translator web app** built using **Microsoft Azure Translator API**.
It allows users to translate text into multiple languages with a **modern animated UI**.

## 🔑 Azure Setup

1. Go to **Azure Portal**

2. Create a **Translator resource**

3. Copy:

   * API Key
   * Region (e.g. `eastus`)

4. Paste them into the app UI
